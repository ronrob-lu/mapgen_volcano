# Volcanic Terrain Mapgen (`mapgen_volcano`)

A **Luanti / Minetest** mapgen mod that transforms the entire endless world into a living volcanic landscape — complete with stratovolcanoes, broad lava calderas, steep cinder cones, glowing tectonic lava fissures, obsidian plains, ash barrens, and subterranean magma chambers — **using only Minetest Game `default` blocks**, with **occasional explosive volcanic eruptions**.

---

## Features

- **Volcanic World Everywhere**: Automatically configures `singlenode` mapgen (and also cleanly overwrites newly generated chunks) so volcanic terrain stretches infinitely in every direction.
- **Zero New Blocks**: Registers **no custom nodes, items, tools, textures, or sounds**. Every block in the world is a standard Minetest Game `default` node (`default:stone`, `default:cobble`, `default:obsidian`, `default:coalblock`, `default:gravel`, `default:desert_stone`, `default:desert_cobble`, `default:desert_sand`, `default:silver_sand`, `default:lava_source`, `default:dry_shrub`, and standard `default:stone_with_*` underground ores). Transient flying eruption debris uses a non-saved entity (`static_save = false`) textured with `default` textures that turns into `default` blocks on landing, leaving zero unknown nodes or objects if the mod is ever removed.
- **Three Procedural Volcano Archetypes**:
  - **Stratovolcanoes**: Towering, jagged domain-warped cones with deep sunken lava calderas, obsidian-jacketed central magma conduits, and occasional meandering lava breach channels carved down their flanks.
  - **Calderas**: Broad volcanic basins holding wide glowing lava lakes ringed by dark basalt and obsidian cliffs.
  - **Cinder Cones**: Smaller, steep, ash- and scoria-covered cones with glowing vents.
- **Volcanic Lowlands & Underground**:
  - Global lava sea (`y = 0`) bordered by cooled obsidian shelves.
  - Glowing surface lava fissures snaking across basalt fields, ash barrens, and scorched red tuff badlands.
  - 3D subterranean lava tubes, deep magma chambers, and mineable `default` ores (coal, iron, copper, tin, gold, mese, and diamond enriched near magma).
- **Occasional Multi-Phase Volcanic Eruptions**:
  1. **Ambient Activity**: Loaded dormant volcanoes near players occasionally emit wisps of volcanic smoke and embers.
  2. **Phase 1 — Seismic Rumble Warning**: Deep rumbling audio and escalating ash/spark plumes give nearby players time to spot the active crater and take cover.
  3. **Phase 2 — Crater Explosion & Lava Bomb Volleys**: Detonates the crater throat (respecting area protection mods and refilling the central vent with fresh `default:lava_source` so volcanoes stay active), unleashes a towering pyroclastic plume, deals falloff shockwave damage/knockback (respecting `enable_damage` and `immortal`), and hurls parabolic lava bombs, obsidian boulders, and scoria chunks across the slopes.
  4. **Phase 3 — Ashfall & Cooldown**: Drifting volcanic ash settles around the cone before the volcano enters a cooldown window.
- **Safe Spawn & Respawn**: Automatically places new and respawning players onto dry, solid volcanic ground (never buried in stone or dropped into lava).

## Requirements & Compatibility

- **Engine**: Luanti / Minetest `5.4.0+` (uses modern `core` / `ValueNoiseMap` APIs with automatic fallback to `minetest` / `PerlinNoiseMap` for older 5.x releases).
- **Required mod**: `default` (Minetest Game).
- **Optional mods**:
  - `fire` — hot lava bomb impacts can briefly ignite `fire:basic_flame` on adjacent air.
  - `tnt` — adds `tnt_explode` audio layered with the `default` eruption sounds.

---

## Installation

1. Copy the `mapgen_volcano` folder into your Luanti / Minetest `mods/` directory.
2. Create a **new world** using **Minetest Game** (recommended).
3. Enable `mapgen_volcano` in the world's mod configuration and play!
   *(The mod automatically sets `mg_name = singlenode` for new worlds unless `mapgen_volcano.force_singlenode = false` is set.)*

## Configuration (`minetest.conf`)

All settings are optional and have sensible defaults:

| Setting | Default | Description |
| --- | --- | --- |
| `mapgen_volcano.force_singlenode` | `true` | Automatically configures `singlenode` mapgen so the entire world is generated by this mod. |
| `mapgen_volcano.eruptions_enabled` | `true` | Enables or disables occasional volcanic eruptions. |
| `mapgen_volcano.ambient_smoke` | `true` | Enables gentle ambient smoke wisps rising from nearby loaded craters. |
| `mapgen_volcano.damage_enabled` | `true` | Enables blast and ejecta impact damage (also respects world `enable_damage`). |
| `mapgen_volcano.eruption_check_interval` | `6.0` | Seconds between eruption checks for volcanoes near players. |
| `mapgen_volcano.eruption_chance` | `0.07` | Probability (`0.001`–`1.0`) per loaded nearby volcano on each check. |
| `mapgen_volcano.eruption_cooldown` | `150.0` | Base cooldown in seconds before the same volcano can erupt again. |
| `mapgen_volcano.active_radius` | `180.0` | Maximum horizontal distance (in nodes) from a player for a volcano to erupt. |
| `mapgen_volcano.max_concurrent` | `2` | Maximum number of volcanoes allowed to erupt simultaneously. |
| `mapgen_volcano.blast_radius` | `5` | Base crater explosion radius (`2`–`9`), scaled by volcano size and eruption intensity. |

## Chat Commands

- `/volcano_info` — Reports the nearest volcano's type, coordinates, distance, compass direction, and current status (`dormant`, `ERUPTING`, or `cooling`).
- `/volcano_erupt` *(requires `server` privilege)* — Immediately triggers an explosive eruption at the nearest loaded volcano.

---

## Lua API

Other mods can query or trigger volcanoes via the global `mapgen_volcano` table:

- `mapgen_volcano.get_volcano_in_cell(cx, cz)` — Returns the deterministic volcano descriptor table for grid cell `(cx, cz)`, or `nil`.
- `mapgen_volcano.get_nearest_volcano(pos, search_cells)` — Returns `volcano, distance` for the closest volcano to `pos`.
- `mapgen_volcano.trigger_eruption(pos, intensity)` — Triggers an eruption at the nearest loaded volcano to `pos`.
